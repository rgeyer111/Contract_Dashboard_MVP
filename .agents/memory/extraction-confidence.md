---
name: Extraction confidence
description: MVP extraction-output decision for per-field reliability signals.
---

Every extracted contract field includes a simple High, Medium, or Low confidence level, displayed during review.

**Why:** The user chose explicit confidence signals so reviewers can prioritize verification instead of treating every extracted value equally.

**How to apply:** Keep confidence beside each extracted field in the review flow. Use clear visual distinction while retaining the separate required-field and unknown-value checks.
