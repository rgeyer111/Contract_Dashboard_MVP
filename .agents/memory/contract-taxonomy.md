---
name: Contract taxonomy
description: Fixed contract categories for the MVP.
---

The MVP uses a strict, four-category contract taxonomy: Maintenance, Software License, Real Estate, and Infrastructure. There is no “Other” category.

**Why:** The user chose consistent extraction and reporting over a more flexible but less focused demo.

**How to apply:** Constrain extraction suggestions and review controls to these options, and do not create an unstructured fallback type.
